# Plataforma de Denúncia e Proteção Animal

Sistema desenvolvido com Flask (Python) e HTML/CSS responsivo para denúncias e acompanhamento de maus-tratos a animais, com login e controle de anonimato/identificação.

## Como Executar o Projeto

1. Certifique-se de ter o Python 3 instalado.
2. Instale o Flask:
   ```bash
   pip install flask
   ```
3. Execute a aplicação:
   ```bash
   python app.py
   ```
4. Acesse no seu navegador: `http://127.0.0.1:5000`
